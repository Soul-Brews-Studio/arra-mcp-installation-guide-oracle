# Use Sonnet for well-scoped team agent tasks

Opus agents died silently on first spawn (19 ghost panes, zero output). Sonnet agents delivered both fixes in <3 minutes on second spawn. For team agents with clear instructions (literal file paths, line numbers, exact changes), Sonnet is faster, cheaper, and more reliable. Save Opus for tasks requiring judgment, not execution.
