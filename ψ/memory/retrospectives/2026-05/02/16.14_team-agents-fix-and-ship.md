## AI Diary

The team agents experience was revealing. First spawn with Opus — both agents died without a trace. No error, no commit, no report. 19 tmux panes left behind as ghosts. Second spawn with Sonnet — both delivered in under 3 minutes. Sonnet was faster and more reliable for these focused, well-scoped tasks.

The tmux cleanup was the worst part. After killshot eliminated 19 panes, 2 zombie panes survived with stale claude.exe and zsh processes. `tmux kill-pane` failed silently. Only `kill -9` on the actual PIDs worked. This is a real UX problem — when team agents break, they leave the terminal unusable.

But the outcome was good: 2 PRs shipped in 20 minutes, fixing bugs that had been open since the start of the session. The team-agents pattern works when tasks are well-scoped and agents get clear instructions with literal file paths and line numbers. The first failure was likely because Opus agents spent too long thinking and timed out.

I also noticed that spawning agents creates a LOT of tmux panes — 19 from 2 agents is excessive. Each respawn adds more without cleaning old ones. The killshot script is essential but incomplete — it kills pane content but not the pane containers themselves.

## Honest Feedback

**Friction 1: Silent agent death.** First spawn — both agents vanished without error. No crash log, no partial output, nothing in tmux. The only way to discover they died was `ps aux | grep`. Team agents need a health check or crash notification.

**Friction 2: Tmux pane accumulation.** 19 ghost panes from 2 agents. Killshot killed 19 but 2 survived as zombies. Had to `kill -9` PIDs manually. The cleanup tools don't fully clean.

**Friction 3: Opus vs Sonnet for agents.** Opus agents timed out or died. Sonnet delivered in <3 minutes. For well-scoped tasks with clear instructions, Sonnet is the better choice — faster, cheaper, and apparently more reliable as a teammate.

## Lessons Learned

1. **Use Sonnet for team agents with well-scoped tasks** — Opus thinks too long and may timeout. Sonnet executes fast when instructions are clear.
2. **Killshot doesn't kill pane containers** — need `kill -9` on PIDs after killshot. File as bug.
3. **Team agents need literal paths** — never pass shell variables. Every file path, line number, and command must be concrete.
